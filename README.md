## 📖 简介

NovelMaker 是一款运行在 Android 设备上的小说写作应用。它将专业写作工具的核心功能浓缩于移动端，支持本地项目管理、纯文本编辑和 DeepSeek AI 辅助创作，帮助你在任何地方随时捕捉灵感。

**所有数据 100% 存储在本地**，无需注册账号，无需联网（AI 功能除外）。

---

## ✨ 功能特性

### 📁 项目管理
- 创建、重命名、删除小说项目
- 项目自动统计章节数和总字数
- 项目目录结构：`大纲/` `小说主体/`

### ✍️ 编辑器
- 纯文本编辑，带行号显示
- 撤销/重做（30 步历史）
- 双指缩放调节字体大小
- 侧边栏文件树（文件夹展开/折叠）
- 自动保存

### 🤖 AI 写作助手（DeepSeek）
- **Plan 模式**：AI 辅助构思大纲、角色设定、章节规划，支持方向选择
- **Agent 模式**：AI 直接撰写章节正文
- **多对话标签页**：每个项目最多 5 个独立对话，各对话记录独立保存、互不干扰
- **联网搜索**：AI 内置 webSearch 工具，可联网搜索（优先 Bing、Google 备选），遇到不了解的信息或没见过的文体时自动搜索
- **AI 回复编辑**：长按 AI 回复可修改内容或删除该条
- **对话 Markdown 渲染**：AI 输出支持 Markdown（标题/粗体/代码/列表/引用等），编辑时仍为纯文本
- **工具调用折叠**：AI 的读取/写入/搜索等工具调用与结果默认折叠展示
- **定稿主动引导**：章节较多后 AI 主动建议标记定稿，并说明缓存命中、风格一致等好处
- **思考强度可调**：不思考 / 高 / 最大三档全局切换，工具调用轮次可自定义
- 流式对话，逐字显示回复
- Function Calling：AI 可读写项目文件、联网搜索
- Token 用量统计（系统提示词 / 对话 / 工具调用）
- 缓存命中优化（KV-Cache，仅固定前缀标记缓存）

### 🎨 界面
- Material 3 设计语言
- 支持浅色 / 深色 / 跟随壁纸三种主题
- 引导页（欢迎 → 权限 → 主题选择）
- 首次使用步骤引导教程

### 📊 数据管理
- Token 用量可视化（分段进度条）
- 系统提示词只读浏览
- 聊天记录管理（按项目展开查看各对话，可逐个对话或整项目删除）
- 定稿章节标记（纳入缓存前缀，上限默认 50、批量淘汰默认 20）

## 🎓 新手教程

NovelMaker 为首次使用的用户提供了内置的**步骤引导教程**，帮助你快速上手。

### 触发条件
- 首次完成引导页后，进入首页自动弹出
- 教程状态存储在本地设置中，不会重复弹出

### 教程步骤

**首页教程（3步）**
| 步骤 | 内容 |
|------|------|
| Step 1 | 欢迎介绍 — 了解 NovelMaker 的核心功能 |
| Step 2 | 创建项目 — 高亮 FAB 按钮，引导创建第一个小说项目 |
| Step 3 | 管理项目 — 介绍点击进入编辑器、长按菜单操作 |

**编辑器教程（5步）**
| 步骤 | 内容 |
|------|------|
| Step 1 | 文件树 — 介绍侧边栏文件管理、新建/重命名/删除、标记定稿 |
| Step 2 | 撤销与重做 — 30 步编辑历史回退 |
| Step 3 | AI 助手 — 引导使用 DeepSeek AI 写作辅助（Plan/Agent 模式） |
| Step 4 | 保存与设置 — 手动保存、快捷设置、自动保存说明 |
| Step 5 | 开始写作 — 行号、双指缩放、字数统计 |

### 跳过早关闭
- 点击右上角「跳过」可随时退出教程
- 所有步骤完成后自动标记为已完成
- 如需重新体验，可清除应用数据后重新启动

## ⚙️ 设置功能详解

设置页面按功能分为以下模块：

### 🎨 界面主题
| 选项 | 说明 |
|------|------|
| 跟随壁纸 | 根据系统壁纸自动适配动态主题色（默认） |
| 浅色模式 | 清爽明亮的界面 |
| 深色模式 | 护眼省电的暗色界面 |

### ✍️ 编辑器设置
| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 字体大小 | 编辑器文字大小，10-32 范围可调 | 16 |
| 行间距 | 编辑器行间距，1.0-5.0 范围可调 | 5.0 |
| 自动保存 | 编辑内容自动保存到本地文件 | 开启 |
| 定稿上限 | AI 缓存前缀中最多包含的定稿章节数（0=无限制） | 50 |
| 批量淘汰 | 超限时一次移除最早的 N 个定稿章节 | 20 |

> 字体大小和行间距也可以在编辑器内的「⚙️ 快捷设置」面板中快速调整。

### 🤖 AI 写作设置
| 设置项 | 说明 |
|--------|------|
| API 地址 | DeepSeek API 端点地址（默认 `https://api.deepseek.com`）|
| 模型名称 | 使用的 AI 模型（默认 `deepseek-chat`）|
| API Key | 你的 DeepSeek API 密钥 |
| 流式回答 | 逐字显示 AI 回复内容（推荐开启）|
| 思考强度 | 不思考 / 高 / 最大 三档，全局生效 |
| 工具调用轮次 | AI 一轮对话调用工具的最大次数（-1 = 无限制，默认 5）|
| 页面纯文本模式 | AI 打开网页时提取正文纯文本（默认开启），关闭则返回原始 HTML |
| 聊天记录管理 | 按项目展开查看全部对话（最多 5 个）及消息数，可逐个对话删除或整项目删除 |
| Token 用量统计 | 查看各项目的 Token 消耗（含系统提示词/对话/工具调用分段统计）|
| 系统提示词 | 浏览当前项目的系统提示词内容（只读）|

### 💾 备份与恢复
| 功能 | 说明 |
|------|------|
| 备份 | 选择项目，设置密码，生成 `.nmbak` 格式的加密备份文件（含项目文件、全部对话标签页、Token 统计与系统提示词） |
| 恢复 | 从本地备份列表或文件选择器中选取 `.nmbak` 文件，输入密码还原 |
| 加密 | 使用 AES-256 (CBC/PKCS5Padding) + PBKDF2 密码派生加密 |
| 文件关联 | 支持通过文件管理器直接打开 `.nmbak` 文件触发恢复 |

## ⚙️ 配置 AI 功能

1. 获取 [DeepSeek API Key](https://platform.deepseek.com/)
2. 打开应用 → 设置 → AI 写作设置
3. 填入 API 地址（默认 `https://api.deepseek.com`）
4. 填入模型名称（如 `deepseek-chat`）
5. 填入 API Key
